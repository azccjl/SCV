# SCV Climate Explorer portable package

Double-click `start_scv.bat` to start the application. The first launch creates a local Python virtual environment and installs dependencies, so Python 3.10 or newer and an internet connection are required once.

The included sample data is in `data/local`. To use another data directory, set `SCV_DATA_DIR` before launching the app. The application opens at http://127.0.0.1:8501/.
